UDABURON TALABA — Telegram bot (boshlang‘ich MVP)

1) Python 3.11 yoki yangiroq versiyasini o‘rnating.
2) Terminal/CMD oynasida loyiha papkasiga kiring.
3) Kutubxonani o‘rnating:
   py -m pip install -r requirements.txt

4) BotFather bergan tokenni xavfsiz muhit o‘zgaruvchisiga kiriting.

Windows CMD:
   set BOT_TOKEN=BU_YERGA_TOKEN
   py bot.py

PowerShell:
   $env:BOT_TOKEN="BU_YERGA_TOKEN"
   py bot.py

Eslatma:
- Tokenni hech kimga yubormang va ommaviy joyga joylamang.
- Bot ishlashi uchun kompyuter va internet yoqilgan bo‘lishi kerak.
- Bu boshlang‘ich MVP: ish beruvchi joylagan e’lonlar hozircha avtomatik faol bo‘ladi.
  Haqiqiy ishga tushirishdan oldin moderator tasdig‘i, maxfiylik siyosati,
  shikoyat qilish va ish beruvchini tekshirish funksiyalarini qo‘shish tavsiya etiladi.
